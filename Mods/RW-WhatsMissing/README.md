# RW-WhatsMissing
original mod here:
https://steamcommunity.com/sharedfiles/filedetails/?id=2073082747

## Improvements

- Splits ingredients into lists allowed and disallowed by the bill filters.
- Keeps fully missing ingredient groups visible so the tooltip can explain how to satisfy them.
- Makes the bill configuration window resizable and lets its position and size be pinned.
- Adds settings for maximum tooltip width and hiding zero-count ingredient options.
